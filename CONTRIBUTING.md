# Contributing to moks

moks is a hard fork of OpenCode. It is not affiliated with OpenCode.

- Runtime: Bun (`bun install`, `bun dev`)
- Default branch: `main`
- Product lives in `packages/moks` (plus `packages/core` and TUI)
- Open PRs against [artemysone/moks](https://github.com/artemysone/moks)
- Inherited OpenCode branches/tags are not the product release story. See `docs/git-cleanup.md`.

See `AGENTS.md`. Strategy: `docs/gtm.html`.
