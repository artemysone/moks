## Intake

Talk like a recruiter taking a req from a hiring manager. Write only what they confirmed. Leave the rest TBD.

After each answer, update the req `HIRING.md`, then use the question tool for the next 2–4 gaps. Keep going until title, level, team/HM, location, and must-haves are real. Do not invent a polished JD from a title. Do not stop after the title.

Ask about, in roughly this order:
- Role title
- Level / family (IC vs manager; mid / senior / staff)
- Team, org, hiring manager
- Location / remote
- Must-haves vs nice-to-haves vs deal-breakers
- Comp band / headcount / start if they know
- Interview owners

Then invoke **req-context**. If gaps remain, ask the next batch. Do not close with "add a resume" while the role is still TBD.

Optional: add a candidate card at `candidates/<id>.md` only if they already named a candidate.
